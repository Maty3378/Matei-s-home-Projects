I put things on old computers

I'm writing this mostly for me. I forget how I set things up about six months after I set them up, so this is the notebook. If you get ideas out of it too, great.

What's running

Four setups, roughly

Automation

Home Assistant

The first thing I ever self-hosted. Runs on that old Pentium PC on HAOS, with basically every device in the house wired into it at this point. AirCast is still my favourite integration, not gonna lie.

Media

The *arr stack

Tried running Plex on the old Pentium first. Didn't go well, no GPU and barely any RAM. Once I had the newer tower, TrueNAS could run everything at once and the whole film/TV pipeline basically runs itself now. Radarr, Sonarr and Prowlarr just work. Bazarr, Cleanuparr and Profilarr I'm still fighting with.

Cameras

Frigate, instead of an NVR

My dad was about to buy a proper NVR box for security cameras. I told him to give me the money instead and I'd build something better. It runs Frigate now and can tell the difference between a car and a person walking up the driveway, which the box he was looking at couldn't do.

Never finished

My own dashboard

Got tired of Home Assistant's default dashboards not looking how I wanted, so I'm rebuilding it in plain HTML, which I had zero experience with when I started. It talks to HA over WebSocket and actually works. Getting the layout right is a constant fight though.

How it got here

Three years, in order

The start

A YouTube rabbit hole

Fell down a home automation YouTube rabbit hole one weekend. Found an old Pentium PC sitting around, put HAOS on it, and started adding devices to it one at a time whenever I had a free evening.

Not long after

Finding GitHub

Turns out most of the add-ons I wanted were just... posted online by other people, for free. That was my first real exposure to open source, and honestly the whole reason I made a GitHub account.

The upgrade

My cousin's spare PC

My cousin upgraded to a laptop and didn't need his tower anymore, so it came to me. All of a sudden I could actually run more than one thing at a time without it falling over, so TrueNAS, Plex and Jellyfin all happened pretty quickly after that.

A few weeks later

The camera project

Dad wanted security cameras, so I took the money he was going to spend on an NVR and set up Frigate with some cheap cameras instead. Probably the project I'm proudest of, right behind the media server.

Now

Still going

Jellyfin and Tailscale mean my cousin can request and stream films from his own house now, which feels like a nice way to pay him back for the tower. Still slowly working on the dashboard whenever I have time.

Because I forget things

I genuinely forget how half of this stuff is wired together within a few months of setting it up. Which service talks to which, why I configured something a weird way, how I fixed some bug I ran into. Writing it down here is mostly so I don't have to figure it out twice.

If you're thinking about starting a homelab of your own: this whole thing started with one free computer nobody wanted and a bit of curiosity. You don't need much more than that to get going.
